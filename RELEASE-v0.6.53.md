# GameWeave v0.6.53

This signed release introduces the GameWeave interface. Existing installations can update in place without moving game files, prefixes, or profiles.

- The redesigned Library keeps Steam and Windows games side by side, with a selected-game pane and dedicated detail tabs.
- The Windows EXE installation wizard brings runtime selection and install status into one flow. It shows activity rather than an estimated percentage if the installer does not report progress.
- The Tools hub and Appearance settings share the redesigned glass interface.
- Carbon Green, Blue & Purple, Red & Orange, and Teal & Green use their matching logo gradients. Soft light moves through the background ribbons. In-app and system Reduce Motion keep the ribbons still.

Use **Check for updates** in an existing installation. For a fresh install, use the signed x86-64 AppImage (Steam Deck Desktop Mode and compatible Linux desktops) or the amd64 DEB (compatible Debian/Ubuntu-based desktops).
