# GameWeave v0.6.54

This update finishes the desktop rebrand. The native window title and Linux applications menu display **GameWeave**, and the desktop icon uses the Carbon Green GW logo. The interface, all four themes, and the animated backgrounds are unchanged.

Existing installations can use **Check for updates** as usual. The package identity and signed update channel are unchanged, so it updates in place without moving games, settings, or Proton prefixes. If a launcher or dock pin still shows a cached old icon, open GameWeave from the applications menu and pin the new entry.
